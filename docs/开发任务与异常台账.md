## 使用规则

- 状态：`待开始`、`进行中`、`阻塞`、`已完成`、`暂缓`。
- 每项任务记录验收依据、实际结果和异常编号；代码提交后补充 commit。
- 异常只记录可复现的问题、影响、当前规避方式和后续动作，不用口头描述替代复现步骤。
- 依赖外部账号、真机、Apple 权限或客户口径的项目，先记录为阻塞／待确认，不把未验证结果标为完成。

## 当前风险与决策

| 编号 | 风险／决策 | 当前结论 |
| --- | --- | --- |
| R001 | 当前工作区有大量既有未提交删除和修改 | 保留，不做清理；新增代码避免覆盖 |
| R002 | 首期仅个人测试版 | 不做公开上架、账号、云同步和分发流程 |
| R003 | 公共天气／节假日允许联网 | 个人业务不上传；网络失败使用内置数据／缓存 |
| R004 | 调休补班周末 | 国家官方明确补班的周末视为工作日，原定提醒照常 |
| R005 | 学生请假 | 只记录姓名和请假信息，不建立学生事务关联 |
| R006 | 停止循环 | 保留当前、历史和未来已完成记录，只取消未来未完成记录 |
| R007 | 通知补齐 | 启动和恢复前台时自动补齐；打开时间不固定，长期未打开的风险待真机验证 |
